# Set up the prototype
## 1. Make private working documents
Create a Google Drive folder for one assignment. Create four Google Docs using the matching files in templates:
Assignment & Plan; Research Notes & Sources; Working Outline; Draft.
Copy the rendered template text into each document. The draft starts with only a title. Add actual assignment instructions and known dates; leave unknowns explicit.

## 2. Set up the coach
Create a ChatGPT Project. Paste coach/PROJECT_INSTRUCTIONS.md into its project instructions. Replace the five link placeholders in that private copy. If the interface rejects the length, shorten wording while retaining authorship, read-only, retrieval-honesty, and save rules.
Instructions stored in this repository do not automatically become ChatGPT instructions. No AGENTS.md is required for the student's workflow.

## 3. Verify the account connection
If the student's account offers Google Drive access, connect the intended Google account and review the available permissions. Select read-only access if offered. The instruction not to edit is a behavioral rule, not a technical permission restriction.
Add the intended connected sources using the available interface. A folder URL alone does not grant access. Features depend on account and workspace settings.
Do not assume automatic folder discovery or immediate synchronization.

## 4. Run a real access test with sample content
Prompt:
"Read the four project documents linked in your instructions. Do not change files. List which you could read, quote the current Next step line from Assignment & Plan, and suggest one small task. Say what you cannot access."

Change Next step manually to a new distinctive sample task. Start a fresh chat within the same project and ask it to retrieve that line again. Verify the exact updated text and source identity. Run docs/PILOT.md.
If it cannot retrieve the update, the connected MVP has not passed. Investigate the account's supported integration before claiming continuity. An uploaded file is a snapshot, not live Google Docs.

## 5. Use it
Student: "Let's work" or a specific request.
Coach reads, asks, organizes, and suggests. Student edits Google Docs.
At a Quick save reminder, save the useful artifact and, when relevant, the small status update.

## Manual fallback
Paste relevant current document excerpts into the chat when connected retrieval is unavailable. Label this as manual mode, not a successful live-folder integration.

## Maintainer reference
Official project guidance: https://learn.chatgpt.com/docs/projects
The kit assumes account-level validation; it does not promise a particular plan, menu layout, or refresh delay.
