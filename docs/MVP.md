# MVP scope — 0.1
## Objective
A student can start a small task, organize research into their own ideas, save progress, and resume from current documents without reconstructing the project.

## Included
One coach, four coaching contexts, four Google Docs templates, read-only source use, student-controlled edits, milestone save reminders, and a repeatable pilot.

## Not included in 0.1
Custom UI, API service, automatic Google Docs edits, automatic close detection, background notifications, parent dashboards, grades, or generated assignment prose.

## First pilot
Use a book-reading session: capture dictated recollections; identify the source without guessing an edition; group student ideas; link verified passages; build a provisional outline; save; reopen in a fresh chat.

## Release decision
Pass the access and behavior checks in PILOT.md. Observe at least three short student sessions.
Look for an easy first action, useful organization, a bounded research task, and accurate resumption. Ask the student which part felt like extra work.
If manual saving is too burdensome, simplify the artifacts or reminders before adding software.

## Later decisions
Only consider a custom interface or integration after the pilot identifies a specific unmet need. Keep student work separate from reusable product files.
