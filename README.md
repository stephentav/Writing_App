# Research & Writing Coach — MVP
A lightweight coaching kit for an 11th-grade research project. The student works in ChatGPT and Google Docs; this repository distributes reusable instructions and templates.

**Version:** 0.1 prototype. **Status:** ready for account-level pilot testing; Drive access and coaching behavior have not yet been validated.

## Start here
1. Follow [Setup](docs/SETUP.md).
2. Copy [coaching instructions](coach/PROJECT_INSTRUCTIONS.md) into the ChatGPT project's instructions, replacing links in your private copy.
3. Copy the four [templates](templates/) into Google Docs.
4. Run [pilot checks](docs/PILOT.md) before using real assignment work.

## The product
One conversational coach provides planning, research support, outlining, and feedback on student-authored drafts. It reads connected documents and suggests small updates; the student makes all edits. Save reminders happen at meaningful milestones.

Google Docs is the saved project record. ChatGPT is the coaching interface. GitHub stores the kit, not student work.

No server, API key, custom app, automatic document editing, or background reminders are included. A folder link does not grant access or guarantee fresh retrieval. Setup includes a read-and-refresh test and an honest manual fallback.
