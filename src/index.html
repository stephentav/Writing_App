A quiet place to make progress

This prototype helps you capture notes, keep source records, organize an outline, and plan your next work session.

Working now: local files, previews, project records, reviewed saves, audio recording, and an authenticated AI coach.

Not connected yet: Speech transcription. The desk starter questions are fixed prompts; use Ask the AI coach for a live conversation.

Approved project changes go into Writing Room/project.json inside your selected folder. Prior versions go into its history folder. Audio is saved only after a separate approval. Only a folder handle is remembered in this browser.

Use Chrome on Mac. PDFs open in Chrome's viewer. Word .docx files show extracted text, not exact page layout. Older .doc and Google Docs shortcuts need exporting to .docx or PDF first. There is no live Google Docs connection.
